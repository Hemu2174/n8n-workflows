# Kattamuri Hemanth | AI Automation Engineer

An interactive internship showcase documenting the AI automation systems built by Kattamuri Hemanth during the AI Winter Internship 2026 at Mirai School of Technology.

## Live Website

[https://hemanth-n8n.lovable.app](https://hemanth-n8n.lovable.app)

The site presents the work as a scrollable portfolio rather than a plain project list. It combines project workflow screenshots, technical skills, implementation challenges, and a reflection on applying AI to healthcare, HR, productivity, and business processes.

## Highlights

- Six AI automation systems built with n8n.
- NASA Astronomy Picture of the Day email automation.
- HR policy assistant using RAG, Pinecone, OpenAI, and Google Drive.
- Telegram physiotherapy assistant with patient intake and appointment booking.
- Calendar and appointment scheduling agents using Google Calendar and Gmail.
- Webhook-based Markdown-to-HTML email generation pipeline.
- Responsive dark/light theme with scroll-reveal animations.

## Site Sections

1. **Hero**: Internship context, professional focus, and impact metrics.
2. **Internship Structure**: Implementation-first learning approach and core skills.
3. **AI Systems**: Detailed descriptions and workflow images for each project.
4. **Challenges and Learnings**: Debugging, data flow, prompting, memory, and system design lessons.
5. **Reflection and Career Impact**: Domains explored and future areas of focus.
